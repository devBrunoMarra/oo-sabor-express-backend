# OO Sabor Express 🍽️

OO Sabor Express is a Python project developed to practice **Object-Oriented Programming (OOP)** concepts.  
The application simulates a restaurant management system, allowing registration, activation, and evaluation of restaurants.

This project was created as part of a learning path focused on Python and OOP fundamentals.

---

## 🚀 Features

- Register restaurants with name and category
- Activate or deactivate restaurants
- List all registered restaurants
- Add customer evaluations (ratings from 1 to 5)
- Calculate and display the average rating of each restaurant

---

## 🛠️ Technologies Used

- **Python 3**
- Object-Oriented Programming (OOP)
- Git & GitHub for version control
